{{- /* One dataset rendered as a card, for the dataset grid. Takes (dict "page" ). The full resource portal cards tools, hardware and protocols through this partial too, and files them by taxonomy. This site carries the datasets only, so the card is the dataset form of it: a picture, the description, and a guide per access route. The card is a single click target, with the title's link stretched over it in CSS and the guide links riding above it. */ -}} {{- $page := .page -}} {{- $comingSoon := eq ($page.Params.status | default "released") "coming-soon" -}} {{- $modality := $page.Params.modality | default slice -}} {{- $access := $page.Params.access | default slice -}} {{- /* Every element is flattened to a string before joining: appending a front matter list to a slice drops it silently, which would leave the terms out of the haystack and make a search for a modality miss the datasets that carry it. */ -}} {{- $haystack := delimit (slice $page.Title $page.Params.description (delimit $modality " ") (delimit $access " ") ) " " -}} {{- /* The card carries its terms as data attributes so the filter script reads exactly the values the front matter uses, and a search haystack so it can match text without a generated index. Both are part of the card's contract, not of the script. */ -}}
{{- /* A dataset's own picture, where it has one. A card without one is exactly the card as it was, so the grid stays mixed until every picture exists. The picture is inset in the card and takes whatever width the card's margin leaves, which varies with the grid, so it is offered at several widths and the browser takes the one its card and screen density need. Serving the artwork full size instead left the browser to downscale it about five times at draw time, which turns hairline illustrations and small labels to mush. A candidate wider than the source is dropped rather than upscaled: enlarging a small original makes a bigger file and a softer picture, so a source narrower than about 1000px cannot fill the widest card on a high-density screen. */ -}} {{- $candidateWidths := slice 360 480 720 980 }} {{- /* The widest card is 411px across a three-column shell and about 488px once the grid drops to one column, less the margin on each side. */ -}} {{- $sizes := "(max-width: 520px) calc(100vw - 4rem), calc(min(33vw, 411px) - 2rem)" }} {{- with $page.Params.card_image }} {{- $card := . }} {{- with .src }} {{- /* errorf marks the build failed but does not halt the template, so the lookup guards everything below it: without the else branch the message is buried under a nil dereference on the first use. */ -}} {{- with resources.Get . }} {{- $source := . }} {{- $rendered := slice }} {{- range $candidateWidths }} {{- if le . $source.Width }} {{- $rendered = $rendered | append ($source.Resize (printf "%dx webp q90 Lanczos" .)) }} {{- end }} {{- end }} {{- if not $rendered }} {{- $rendered = slice ($source.Resize (printf "%dx webp q90 Lanczos" $source.Width)) }} {{- end }} {{- $widest := index $rendered (sub (len $rendered) 1) }}
{{- else }} {{- errorf "card_image %q is not under assets/" . }} {{- end }} {{- end }} {{- end }}
