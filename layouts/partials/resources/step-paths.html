{{- /* The resource paths one workflow step refers to, always as a slice. Takes a step map and returns a slice of page paths. A step's `resource` is a single path or a list of them, so a step like "choose an access route" can show several cards under one heading. Both the step renderer and the backlink scan need the same normalisation. */ -}} {{- $paths := .resource -}} {{- if not (reflect.IsSlice $paths) -}} {{- $paths = slice $paths -}} {{- end -}} {{- return $paths -}}
